Accessible Kanban Board

This demo showcases the comprehensive accessibility improvements including keyboard navigation and screen reader support.

🎹 Keyboard Navigation Guide

General Navigation

  • Tab / Shift+Tab - Navigate between elements
  • Enter - Activate buttons / Edit items
  • Escape - Exit edit mode

Item Actions

  • Shift+Delete - Delete item
  • Shift+↑ - Move item up in column
  • Shift+↓ - Move item down in column
  • Shift+← - Move to previous column
  • Shift+→ - Move to next column
  • Or use Tab to arrow buttons

Screen Reader Features

  • All elements have descriptive labels
  • Actions announced in real-time
  • Column and item counts read aloud
  • Edit mode clearly announced

Visual Features

  • Focus indicators on all interactive elements
  • Arrow buttons in tab order
  • Delete button accessible via Tab
  • Works alongside drag & drop
  • Inherits website colors automatically

Try it: Press Tab to navigate through all controls including arrow buttons, or use Shift+Arrow keys when an item is focused!
