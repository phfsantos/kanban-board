Custom Dialog Styling with ::part()

This demo shows how to use CSS ::part() selectors to customize the delete confirmation dialog.

Available Dialog Parts:

  • ::part(dialog) - The main dialog element
  • ::part(dialog-form) - The form container
  • ::part(dialog-title) - The dialog title
  • ::part(dialog-description) - The description text
  • ::part(dialog-buttons) - The buttons container
  • ::part(dialog-cancel-button) - The cancel button
  • ::part(dialog-confirm-button) - The confirm button

Example Usage:

/* Custom dialog styling */
kanban-board::part(dialog) {
  border: 2px solid #3b82f6;
  border-radius: 12px;
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
}

kanban-board::part(dialog-confirm-button) {
  background: #ef4444;
  color: white;
}

Try it: Add an item to the Todo column, then click the delete icon (×) to see the custom-styled dialog.
